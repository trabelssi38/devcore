## Ajouter un projet
1. Créer `DEV_CORE_DATA\Projects\[nom]\`
2. Creer `DEV_CORE_DATA\Memory\tasks.json` via `dc new project [nom]`
3. Éditer le project name et les missions
4. `dc launch -Project [nom]`
